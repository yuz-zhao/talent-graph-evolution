# TalentGraph 统一算法架构与版本清单

生成时间：2026-08-12T02:03:34.553Z

> 本清单描述当前实际运行版本。AI 参考标签仅用于自一致性回归，不能宣称独立人工金标准确率。

## 数据流

```text
多源采集 -> 质量与隔离 -> 技能本体/证据 -> 简历解析 -> 时间知识图谱
-> 候选召回与融合排序 -> 差距优先级 -> 先修学习路径 -> 行为反馈
-> 生命周期/跨源趋势 -> 统一评测与合规审计
```

## 组件清单

| 阶段 | 组件 | 版本 | 状态 | 证据门控 |
| --- | --- | --- | --- | --- |
| collection | 多源采集与血缘 | collection_pipeline_v2 | production | URL、时间、内容哈希、批次 ID 必须存在 |
| quality | 来源质量、重复与抄袭簇 | multisource_audit_v2 | production | 隔离来源和非独立转载不得进入正式统计 |
| ontology | 技能本体与跨源证据 | cross_source_evidence_v1.0.0 | production | 每条正式证据必须有文本、URL 和版本 |
| resume | 版面感知简历解析 | resume_parser_v2 | production | 学习中和目标技能不得作为已掌握技能 |
| rag | 证据约束 RAG | evidence_rag_v1 | production | 无合格证据必须拒答 |
| new_job | 新岗位发现 | new_job_discovery_v3.0.0 | production | 公司、来源、地区、稳定性和时间外验证门控 |
| evolution | 岗位技能演化与生命周期 | job_skill_evolution_v2 | production | 低窗口或低来源支持返回 insufficient_evidence |
| cross_source_lag | 跨源领先滞后 | cross_source_lag_v1 | exploratory | 至少 4 个活跃来源月和 6 个重叠月 |
| graph | 时间属性知识图谱 | graph_contract_v2 | production | 图契约、主键、关系端点验收 |
| matching | 两阶段召回、融合排序与多样化 | diversified_feedback_matching_v8 | production | 缺失维度重归一化；无证据维度不可用；GNN 影子值不参与排序 |
| gnn | 异构 GraphSAGE 辅助表征 | hetero_graphsage_unsupervised_v1 | shadow_evaluation | 无真实结果边与独立下游评估时禁止进入生产融合或声明人岗准确率 |
| gap | 证据与成本约束差距优先级 | evidence_cost_gap_priority_v2 | production | 要求重要性、置信度、职业相关性和学习成本全部可解释 |
| learning | 先修约束学习路径 | verified_prerequisite_learning_path_v2 | production | URL 仅来自 is_verified=1；无资源则留空 |
| feedback | 曝光与行为反馈闭环 | diversified_feedback_matching_v8 | production | 曝光未点击不直接作为负反馈 |
| compliance | 公平性与隐私控制 | fairness_privacy_audit_v1 | production | 不推断敏感属性 |
| evaluation | 统一可复现评测 | claim_scoped_acceptance_v2 | production | 每项指标必须绑定其金标与声明范围 |

## 存储边界

- PostgreSQL：用户业务、匹配、学习计划、授权和审计记录。
- Neo4j：岗位、技能及带来源和时间的证据关系。
- Qdrant：真实 BGE 向量证据索引。
- 文件产物：gold、时间快照、评测报告和算法清单。

## 禁止宣称

- independent human-gold accuracy
- supervised GNN talent-job accuracy
- causal claim from lag correlation
